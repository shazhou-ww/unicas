# Repository documentation

This directory contains contributor, task-workflow, release-engineering, and
other repository-development documentation. It is not a source directory for
the public site at `https://docs.unicas.work`.

- [Repository tasks](repository-tasks.md) defines the shared task lifecycle and
  publication rules.
- [Managed issuer retirement](managed-issuer-retirement.md) preserves the
  historical two-stage production retirement and rollback procedure.

Published service standards, integration guidance, operations guidance, and
legacy public references are owned by
[`packages/docs-site/content/`](../packages/docs-site/content/). Package-specific
documentation remains with its owning package, including the private Spaces App
operations guide in [`packages/spaces/README.md`](../packages/spaces/README.md).
